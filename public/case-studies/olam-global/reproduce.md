## Native artifact build

scripts/olam-artifacts.mjs uses @oai/artifact-tool in the Codex primary runtime. It writes editable PPTX with source/appendix hyperlinks, formula workbook and PNG previews; required font/integrity/layout validators finalize the native deck in a unique revision directory. scripts/olam-pdfs.py writes the checked slide PDF, country atlas and reports. scripts/olam-verify.py runs accounting, physical, source/input/claim and requirement coverage checks. npm run build includes TypeScript and portfolio regression checks. scripts/olam-bundle.py packages final files, code, permitted clean data and manifest/checksums.

## Package execution

The archive includes the global and inherited Nigeria calculators, numerical regression test, website component, dependency lock, authoring/retrieval scripts, clean inputs and validation receipts. From the extracted root, install the locked Node dependencies with `npm ci`, then run `node --import tsx tests/olam-africa-strategy.ts` and `python scripts/olam-verify.py --native`. Exact Python, statistical, PDF and artifact-tool versions are in environment.json. Native authoring requires the documented Codex primary runtime and its immutable presentation helpers; public-source retrieval requires network access. The complete portfolio build requires the full GitHub checkout at https://github.com/ManashProtimDeori/Manash-Protim-Deori rather than only the research archive.

Git stores the complete archive in bounded binary parts under research/olam-global/package-parts. The portfolio build runs scripts/olam-materialize-package.mjs to verify each part and the complete archive, then writes the original single ZIP at the public download URL. This transport arrangement preserves every packaged file. Running olam-bundle.py refreshes both the archive and its parts.
